# Pasta de imagens

Coloque as fotos aqui, seguindo esta organização (os nomes de arquivo abaixo já são os que o index.html está esperando):

- `hero/principal.jpg` — foto grande do topo (retrato ou consultório)
- `hero/secundaria.jpg` — foto pequena sobreposta no topo
- `sobre/atendimento.jpg` — foto da seção "Oi, eu sou a..."
- `trajetoria/formacao.jpg` — foto da seção de formação/trajetória

Dica: fotos na vertical (proporção 3:4 ou 4:5) funcionam melhor nesses espaços.
Depois de adicionar os arquivos, veja no chat como trocar os placeholders `[ ... ]` pelas tags `<img>`.
